INTRANET ECOFLY - VERSION INICIAL

ARCHIVOS
- index.html: estructura y contenido de la intranet.
- styles.css: estilos adaptables para escritorio, tableta y móvil.
- script.js: navegación, búsqueda, filtros y ventanas informativas de demostración.
- assets/ecofly-logo.jpg: logotipo facilitado.
- assets/paleta-colores.jpg: referencia de la paleta corporativa facilitada.

CÓMO ABRIR
1. Descomprime el ZIP si lo has recibido comprimido.
2. Abre index.html con Chrome, Edge o Firefox.
3. Para publicarla, sube la carpeta a un servicio de alojamiento web estático o usa una plataforma compatible.

FUNCIONES QUE YA FUNCIONAN EN ESTA DEMO
- Navegación entre secciones.
- Diseño adaptable a escritorio y móvil.
- Búsqueda y filtros de las tarjetas de documentación.
- Ventanas informativas para las tarjetas.
- Formulario de consulta demostrativo (no envía ni guarda datos).

FUNCIONES QUE REQUIEREN CONEXIÓN O CONFIGURACIÓN EXTERNA
- Documentos reales: añadir enlaces de Google Drive/Docs o archivos alojados.
- Calendario: insertar un Google Calendar y configurar sus permisos.
- Formulario con recepción de respuestas: conectar Google Forms u otro servicio.
- Directorio: preparar una vista segura de Google Sheets o una fuente de datos; no publicar directamente el Excel completo.
- Inicio de sesión y permisos: alojar la página en una plataforma que controle el acceso, o configurar autenticación externa.
- Noticias editables por el equipo: usar Google Sites, un CMS o una fuente de datos conectada.

PRIVACIDAD
El Excel de ECOFLY contiene una hoja de trabajadores con datos personales y campos salariales, además de datos de clientes y proveedores. Esta demo no importa ni muestra esos registros. Antes de conectar datos, crea vistas con los campos estrictamente necesarios y limita el acceso a personal autorizado.

NOTA
Esta es una intranet visual inicial. No tiene backend, autenticación, base de datos conectada ni envío real de formularios. Los contenidos y estados de archivo están identificados como referencias o pendientes cuando corresponde.


ACTUALIZACIÓN: Los seis apartados de Documentación interna y los enlaces de PRL/protocolo de Noticias abren el Google Doc compartido por el usuario. Se añadió un acceso directo a la hoja de cálculo de la base de datos. La imagen adjunta se utiliza en la tarjeta principal de Noticias.
